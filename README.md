# Landing page veterinária — Dra. Bianca Cabral

Landing page responsiva para apresentar serviços veterinários no Rio de Janeiro e facilitar o agendamento pelo WhatsApp. Projeto desenvolvido com HTML, CSS e JavaScript, sem framework ou etapa de build.

**[Ver a página publicada](https://bianca-cabral-veterinaria.netlify.app/)**

## O que a página inclui

- Apresentação da profissional, área de atendimento e serviços para cães e gatos.
- Chamadas para agendamento pelo WhatsApp em pontos importantes da navegação.
- Menu adaptado para celular e seção de perguntas frequentes.
- Layout responsivo e metadados básicos para busca local.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript para o menu móvel

## Executar localmente

Abra `index.html` no navegador. Os estilos estão em `styles.css` e o comportamento do menu em `script.js`.

## Estado do projeto

As fotografias externas são ilustrativas. O número de CRMV `00000` e os links sociais `#` presentes no código são marcadores de conteúdo; devem ser substituídos por dados confirmados antes de usar a página como apresentação profissional definitiva.
